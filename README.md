# apbd_09 — API magazynu (Warehouse)

ASP.NET Core Web API z przedmiotu **APBD** (ćwiczenie 9): przyjmowanie zamówienia na produkt i rejestrowanie go w magazynie za pomocą procedury składowanej.

**Technologie:** C#, ASP.NET Core Web API, SQL (procedury składowane w `sql/`)

**Jak uruchomić:**
1. Uruchom `sql/create.sql`, a potem `sql/proc.sql` na swojej bazie.
2. `dotnet run`
